# ترجمان (Tarjuman - Super Blur Glass Edition)

مترجم فوري عائم فوق التطبيقات (العربية ⇄ الإنجليزية) بتصميم **Super Blur Glass** وأيقونة الريشة التي تنقط حبراً فيروزياً.

## البناء السحابي عبر GitHub Actions:
1. ارفع محتويات مجلد `TarjumanPro` بالكامل (بما في ذلك مجلد `.github` وملف `gradle.properties`) إلى مستودع جديد على GitHub.
2. افتح تبويب **Actions** في المستودع وانتظر اكتمال بناء `Build Tarjuman Glass APK`.
3. حمّل الملف من قسم **Artifacts** وثبّته مباشرة على هاتفك.
